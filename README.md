Toggle Center 
Toggle Center is a responsive e-commerce website for browsing and shopping for smartphones, tablets, and accessories.

Live Demo
https://toggle-center.netlify.app

Features
* Browse smartphones, tablets, and accessories
* Product filtering
* Quick product view
* Interactive shopping cart
* LocalStorage for persistent cart data
* Responsive design for mobile and desktop
* Login and signup pages

Technologies
* HTML5
* CSS3
* JavaScript
* LocalStorage
